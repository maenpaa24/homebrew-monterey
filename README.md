# homebrew-monterey

## How do I install these formulae?
`brew install maenpaa24/monterey/<formula>`

Or `brew tap maenpaa24/monterey` and then `brew install <formula>`.

Or install via URL (which will not receive updates):

```
brew install https://raw.githubusercontent.com/maenpaa24/homebrew-monterey/master/Formula/<formula>.rb
```

## Documentation
`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
